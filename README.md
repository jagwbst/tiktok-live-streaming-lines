## 直播间为什么会先栽在"网络"这一步

TikTok 直播和短视频在协议层有一个关键差异：短视频是单向拉流（下行），对延迟容忍度高，而 RTMP/SRT 推流几乎全是上行，对网络抖动、丢包、IP 归属的敏感度呈指数级上升。当晚高峰运营商之间互联出现拥塞时，共享节点的丢包率能从 0.1% 瞬间跳到 5% 以上，画面变成连续马赛克，平台算法也会把这种"低质量推流源"降权。

对账号的影响更隐蔽。TikTok 风控会在推流握手阶段检测出口 IP 的归属 ASN、历史信誉和注册地情况。一旦一个 IP 段被大量营销号共用，或者被识别为机房段而非住宅 / 当地 ISP 段，就可能触发"看似存在但实际 0 播放""突然终止推流""对账号打标"等连锁反应。换句话说，账号被风控与"我是不是真人操作"无关，更可能只是共享 IP 池里有其他人已经做过违规操作。

这时候专用线路的价值就出现了：从物理层把推流路径走合规的国际专线，而不是普通互联网走 IX、海缆、运营商三方互联的公共路径，前者能拿到稳定的低丢包、明确的出口归属 IP，以及更可控的本地运营商映射。

## IEPL / IPLC / IXP / BGP，分别指什么

跨境专线被宣传得很多，但术语经常被混用。下面四类是当前国内 TikTok 直播圈讨论频率最高、也是 Mkcloud 当前在售的核心产品线：

- **IEPL（International Ethernet Private Line）**：端到端以太网专线，国际以太网专线。常见为单层二层透明链路，延迟低、跳数少，通常用于中国大陆接入点到香港接入点之间的专线通道。
- **IPLC（International Private Leased Circuit）**：传统的国际私用租用电路，从运营商层面拉一根从入口到出口的独享线路，多用于跨海缆的稳定连接，像国内电信 / 联通到日本、美国的 IPLC 是经典场景。
- **IXP（Internet Exchange Point）专线 / 上云互联优化**：通过互联网交换点直连，针对云厂入口对接，特别适合直播源在云上、出口在云上的场景，能大幅压缩云内跨域访问延迟。
- **BGP 多线 / 上云互联**：在国内入口侧接入多家运营商的 BGP 出口，结合动态路由选优，适合需要多运营商兼容性或复杂接入环境的业务。

判断哪种适合自己，关键看三件事：直播源在本地物理机还是云上、目标出口是香港 / 日本 / 美国、国内入口运营商预算。对于 TikTok 直播而言，香港出口通常对应东南亚 / 美区前端的引导，日本出口适合日区直播，美国方向的链路对应美区独立 IP 需求。三种出口在 Mkcloud 里都有对应专线覆盖。

## 直播专线的真正易踩坑点

以下是 TikTok 直播项目里被反复验证过的几个失误点，下单前都值得过一遍：

1. **以为"独享 IP = 防封号"**。TikTok 风控是综合判定，IP 仅是其中一项。账号本身是否真人操作、设备指纹是否干净、是否同一运营商网络反复切换等，都会被风控综合打分。专线只解决网络相关的那一环。
2. **以为"机场能开就能推流"**。机场节点是虚拟共享带宽 + 高复用 IP，没有任何 SLA，跳数还多。推流的负载特性跟节点测试时的下行 pull 完全不同。机场可以用于脚本采集和测速，但不适合 24/7 直播任务。
3. **上行带宽预留不足**。1080P/30fps 至少 4-6Mbps；4K 或多机位 20Mbps 起。预算里至少给自己留 30% 冗余，否则晚高峰抖动直接变成马赛克。
4. **国内入口没绑死运营商**。电信 / 移动 / 联通三线入口不是越多越好，国内团队最好按本地上网运营商选对应入口，例如华南工厂在广东可以选择广东三线 / 广东电信 / 广东移动 IEPL 独享带宽。
5. **把后台店铺和直播间放在同一专线**。TikTok Shop 后台要求高安全性、强固定 IP；矩阵短视频要求高下行、多 IP 轮换；直播要求高上行、低延迟。三种业务用一套网络，结果就是全部都不稳。

## 常见问题

**Q1：TikTok 直播专线和普通机场节点有什么本质区别？**
A1：普通机场使用虚拟加密信道、共享带宽、出口 IP 复用度高，仅适合测试和短视频浏览。专线走的是物理独享链路，配独立入口 + 独立出口 IP，在链路抖动、IP 纯度、SLA 稳定性上都显著优于机场。

**Q2：做美区 TikTok 直播，出口 IP 必须用美国 IP 吗？**
A2：建议用美国本地 ISP（如 Comcast / AT&T）的"住宅型 / 原生型"非机房 IP 段。Mkcloud 沪美 IPLC 配合 BGP 出口可以在出口侧给出非机房的美国映射 IP，但仍需配合 IP 信誉评分（如 scamalytics）做进一步验证。

**Q3：一条专线可以同时推几个账号吗？**
A3：从技术上可以，但不被推荐。多账号共用同一条专线的同出口 IP，会被平台判定为"矩阵同源"，增加关联风控风险。建议一号一专线，单台 VPS 单账号，对矩阵账号同样适用。

**Q4：直播画面只是偶尔出现马赛克，是带宽不够吗？**
A4：大多数情况下不是绝对带宽不够，而是晚高峰线路抖动导致丢包。I PLC / IEPL / IXP 之所以比普通公网稳，正是因为它们绕开了运营商之间的高峰拥堵节点。

**Q5：独享带宽套餐比流量计费贵很多，值得吗？**
A5：如果是单场直播 1-2 小时、码率压得较低，流量计费划算。如果是 4-6 小时长时段直播或多机位输出，独享带宽能避免和共享用户抢峰值，长期看更省心。
